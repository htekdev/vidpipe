# Configure Specification

## Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| REQ-001 | Configure set/get/list supports storage-provider, aws-region, aws-s3-bucket, aws-s3-prefix, aws-dynamodb-content-table and aws-dynamodb-videos-table aliases and corresponding defaults dot notation as non-secret defaults. | P0 |
| REQ-002 | Configure rejects invalid storage provider values before saving and does not expose AWS access-key or secret-key storage aliases. | P0 |
